# PPE Monitoring System

## Overview

PPE Monitoring System is a computer vision–based safety solution designed to monitor Personal Protective Equipment (PPE) compliance in industrial environments. The system analyzes video streams from CCTV cameras, webcams, or recorded footage and detects whether workers are wearing required safety equipment such as helmets, safety vests, goggles, and gloves.

The objective of this project is to improve workplace safety by automatically identifying PPE violations in real time and generating actionable insights for supervisors and safety teams.

---

## Problem Statement

In industrial environments, ensuring that workers consistently wear required PPE is critical for maintaining safety standards. Manual monitoring is time-consuming, prone to human error, and difficult to scale across large facilities.

This project aims to develop an AI-powered monitoring system capable of:

* Detecting workers in video streams
* Identifying PPE compliance
* Flagging safety violations
* Generating reports and analytics
* Supporting real-time safety monitoring
